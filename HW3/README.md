# Perceptron Implementation

There are two python notebooks in this set up implemented 2 parts of the assignment. `perceptron_part1.ipynb` is the implementation for problem 1, while `perceptron_part2.ipynb` is the implementation for problem 2. 

In order to run them:
1. Make sure all files (data, figs and the python fliles) are in the same directory as arranged by the zip file.
2. Make sure to have `pandas, numpy` and `matplotlib` installed.
3. Open the python notebooks using Visual studio code, google colab, kaggle or jupyter notebooks. With any of those options, make sure the data folder is present in the working directory.
4. Run each cell one by one to see results!
