## Intelligent Systems HW 2 (Python Code)


#### Setup instructions
This code has a menu interface to showcase the abilities of the code for all 3 sections.

To run this code, you will require `matplotlib, numpy` and `pandas`. You can install them using the following commands:

```
pip install matplotlib, numpy, pandas
```

#### Running the code
Once you have made sure all the necessary packages are installed, you can run the code using the following command in the terminal, within the directory of the python file `neuron_RS2.py`

```
python ./neuron_RS2.py
```

If the code ran correctly, you should see this:
```
==================================================
NEURON SIMULATION MENU
==================================================
1. Generate R vs I Data
2. Plot R vs I Comparison
3. Plot Voltage Traces
4. Plot Chattering Neurons
5. Exit
==================================================

Enter your choice (1-5):
```

You can navigate by simply entering a number of your choice and hitting enter.

**Note**: In order to run `2.`, you must first run `1.` for both Regular Spiking and Fast Spiking neurons.
